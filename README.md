# SpinR
## Version 1

This is the the first version of SpinR. It has been left available for archiving purposes but is **NOT** completed, **NOT** fully-functional, **NOT** fully-tested, and **NOT** recieving new updates.
If you are looking for the current version of SpinR look for version 2 [here](https://github.com/Heavy-Horn/SpinR/tree/v2).

### Why are there two versions?
SpinR has two versions simply because this version, verison 1, was designed and built as a proof of concept with little to no planning or documentation.
Add on to this the fact that the games main function of the orbs needed to undergo a major overhaul to improve the games functionality and the decision was made to seperate the original version of the game and the new, documented, planned and updated version.
